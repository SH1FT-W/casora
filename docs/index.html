Coming from Hemma

Moving feels like an update.

Casora finds your Hemma dashboards and carries over rooms, tiles, the phone layout and your own cards. Your old dashboard stays untouched.

  1. Make a backup in Home Assistant, just to be safe.
  2. Install Casora and open the Studio. It lists everything that will move.
  3. Choose for each tile you changed: keep yours, take Casora's, or let AI merge the two.

Install

Three steps.
Then it's yours.

With HACS

The setup assistant takes it from there.

  1. In HACS, add a custom repository of type Integration:
    https://github.com/SH1FT-W/casora
  2. Download Casora and restart Home Assistant.
  3. Add the Casora integration under Settings, Devices & services, then open Casora Studio in the sidebar.

Updates arrive through HACS like any other integration. Casora saves a version of your dashboards first and never restarts Home Assistant on its own.

What you need

Casora checks this for you on first start.

  • Home Assistant 2026.9+Required
  • UI eXtension (UIX)From HACS
  • button-cardFrom HACS
  • apexcharts-cardOptional
  • An AI task in Home AssistantOptional

Use UIX instead of card-mod, not both. Helpers, scripts, resources and the theme are created by Casora itself.

Without HACS

Download the latest release, copy its custom_components/casora folder into /config/custom_components/, restart Home Assistant and add the Casora integration. New versions then show up under Settings, Updates.

Privacy

It stays at home.

No cloud.

Casora runs entirely inside your Home Assistant. No account, no analytics, no telemetry.

Your data, your backups.

Dashboards, versions and settings live on your own instance and are part of its regular backups.

AI only if you ask.

AI features stay off until you turn them on, and then use the provider you already set up in Home Assistant.

Optional, and quietly useful.

With an AI task set up, Casora adds a few helpers to the dashboard. Each one shows its cost estimate first, and each has its own schedule: off, automatic or a time you pick.
